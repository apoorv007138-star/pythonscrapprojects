# Contributing

Thanks for taking an interest in this repository!

## Getting started
1. Fork the repository.
2. Clone your fork.
3. Create a branch for your change.
4. Make a focused improvement.
5. Test your changes before opening a pull request.

## Code style
- Use clear, descriptive names.
- Prefer small functions that do one thing.
- Add comments when they explain why something is done.
- Keep examples beginner-friendly.
- Avoid adding dependencies unless they are genuinely needed.

## Before submitting
- Run the relevant script and tests.
- Update documentation if behaviour changes.
- Include a short explanation of what you changed.

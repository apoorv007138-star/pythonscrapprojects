# Python Scrap Projects

A collection of practical Python projects for learning and experimentation.

## Projects

### [BookVault – Personal Library Manager](bookvault/)

A terminal-based library manager built with Python and SQLite. Add and search books, track borrowing and returns, view statistics, and export records to CSV.

**Run it:**
```bash
cd bookvault
python main.py
```

**Run tests:**
```bash
cd bookvault
python -m unittest discover -s tests -v
```

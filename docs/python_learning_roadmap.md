# Beginner Python Learning Roadmap

A practical order for learning Python fundamentals.

## 1. Getting started
- Install Python
- Run a script
- Use the terminal
- Understand errors and tracebacks

## 2. Core fundamentals
- Variables and data types
- Input and output
- Operators
- Strings
- Conditions
- Loops

## 3. Organizing code
- Lists, tuples, sets, and dictionaries
- Functions and return values
- Modules and imports
- Reading and writing files
- Exceptions

## 4. Working with real data
- JSON and CSV
- APIs and HTTP basics
- SQLite databases
- Basic data validation

## 5. Writing reliable programs
- Debugging
- Unit testing
- Virtual environments
- Git and GitHub
- Documentation

## Practice ideas
Build small programs that solve real problems. Start with a simple version, then add validation, tests, and a clear README.

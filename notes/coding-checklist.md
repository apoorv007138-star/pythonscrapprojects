# Coding Workflow Checklist

A small checklist for keeping everyday coding sessions organized.

- [ ] Understand the task before changing code.
- [ ] Break large tasks into smaller steps.
- [ ] Use clear names for variables and functions.
- [ ] Test the happy path and at least one edge case.
- [ ] Read error messages before changing code.
- [ ] Update documentation when behavior changes.
- [ ] Review the final diff before committing.

## Quick Git reminder

```bash
git status
git add .
git commit -m "Describe the change"
git push
```
